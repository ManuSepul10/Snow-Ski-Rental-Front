# 🏔️ Snow Ski Rental – Frontend

Aplicación web para Snow Ski Rental, un negocio dedicado al alquiler de equipos de esquí y snowboard. El proyecto busca ofrecer una experiencia digital moderna, intuitiva y adaptable a distintos dispositivos.

🌐 **Sitio web:** https://snowskyrental.com

## 🚀 Tecnologías utilizadas

- React
- Figma make
- TypeScript
- Vite
- HTML5
- CSS3
- Lucide React
- Git y GitHub

## ✨ Características

- Interfaz responsive y adaptable a dispositivos móviles.
- Presentación de productos y servicios.
- Información de sucursales.
- Navegación intuitiva.
- Componentes reutilizables.
- Integración con el backend para gestionar suscripciones.
- Formulario de suscripción al newsletter.

## ⚙️ Instalación y ejecución

Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

Ingresar al proyecto:

```bash
cd Snow-Ski-Rental-Front
```

Instalar dependencias:

```bash
npm install
```

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

## 🏗️ Compilación

```bash
npm run build
```

## 🎯 Objetivo del proyecto

Desarrollar una aplicación frontend profesional, aplicando buenas prácticas de desarrollo, organización de componentes y consumo de servicios REST.
